# 内容质量 Q 与需求匹配 M（content-v4）

分数由宿主根据记录的分项依据计算和复核，不存在后台评分器。
先固定本次权重与门槛，再评价单篇；不能为推荐某篇临时调权。

| Q 维度 | 权重 |
|---|---:|
| motivation：动机与缺口 | 15 |
| originality：可核实新增贡献 | 15 |
| rigor：设计/证明严谨性 | 25 |
| evidence：证据与主张边界 | 25 |
| reproducibility：可复核性 | 10 |
| figures：图表/论证表达 | 10 |

| M 维度 | 权重 |
|---|---:|
| problem：研究对象和任务 | 45 |
| approach：所需方法/路径的可用性 | 25 |
| context：应用条件与迁移前提 | 20 |
| intent：用户阅读目的 | 10 |

每维 0–5，Q/M = Σ(权重 × 分数/5)，得到 0–100。
M 每维同时引用用户需求与论文内容；只根据摘要的 M 要标“初筛”，不生成最终 S。
软偏好不作为硬性排除。作者、IF、期刊声望与获取难易不加减 Q/M；
预印本缺 IF 是不适用，不扣分。明确的期刊/日期过滤单独执行。

## 综合优先级与门槛

S = Q^α × M^(1−α)，默认 α=0.60，配置允许 0–1；先确认值有效。
用宿主可用的计算器/计算工具核对算术并保留输入，无需用户运行程序。
分数通常保留一位小数；用未四舍五入的值判门槛。

- Q >= 70、M >= 70，且 rigor/evidence >= 3/5，才可进入推荐。
- S >= 85：must_read；75 <= S < 85：shortlist。
- 达不到推荐门槛的已完整评审候选可列 watchlist 或不推荐，并写明原因。
- 用户调整最低 Q/M 仍不能绕过主张审查、核心缺陷或硬约束。

例如 Q=80、M=85 时 S≈81.96；Q=90、M=40 时 S≈65.07，
后者同时未过 M 门槛。综合分不能补偿低匹配或明确证据失败。

## 证据门槛优先于分数

在 [质量审查](quality-evaluation.md) 中逐条核对，并将约束放在评分表旁：

| 情况 | 评分/推荐处理 |
|---|---|
| 缺全文、必要图表、原创性比较或分项证据 | 对应维度未知；最终 Q/S 待评 |
| 核心主张未审或 unresolved | 最终 Q/S 待评 |
| major/critical 疑点尚未解决 | needs_expert_review，最终 Q/S 待评 |
| qualified：需收窄才成立的主张 | evidence 至多 3/5、置信至多 medium、推荐至多 shortlist，并展示保守结论 |
| 针对性核查确认核心 unsupported | 不推荐；S 不计算 |
| 核心 contradicted 或已确认核心缺陷 | 排除/待专家处理；S 不计算 |
| 用户硬约束未知或期刊严格评级未核验 | needs_verification，不进入符合条件的推荐 |
| 用户硬约束确认失败 | 明确排除，不因高分保留推荐 |

这些是审慎的阅读策略，不是经过统计验证的科学定律。agent 需要自行核对是否满足，
不能声称“脚本强制通过”“自动防止一切 overclaim”。

## 缺失与置信

缺失用 null/待评，不填 0、均值或凭印象补齐，也不把剩余维度重新归一化。
如需范围，分别以未评维度 0/5 计算敏感性上下界；它们不是统计置信区间，
不能替代最终分用于推荐。保留原始分项与受限后的有效分数，不静默修改依据。

review_confidence=low/medium/high 是证据充分性的评审判断，不是经过校准的正确概率。
缺全文/看图能力/核查时间是评审限制，不能直接写成论文质量差。
quality_pending、pending_access 与 excluded 分开。

人工标签可用于检查一致性与调整权重，需独立样本/保留验证集；
小样本的一致不外推科学正确率或全领域召回。当前权重未做领域基准验证。
