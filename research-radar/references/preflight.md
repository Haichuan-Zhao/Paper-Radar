# 配置与每次运行前检查

配置是 agent 读取的普通 Markdown，不是解析器输入。用户只维护 USER_CONFIG.md。
公开分发 [空白示例](../USER_CONFIG.example.md)，首次使用由 agent 的文件工具复制到
当前研究工作目录；指定路径优先，不扫描整个用户目录，不覆盖已有副本。
安装目录和公开示例保持不含个人信息。无文件写入工具时告知限制，由用户保存副本，
可暂用其直接提供的配置内容；不要假称已创建文件。

## 合并本次需求

聊天中的明确要求优先于保存的任务设置。保留原话、硬约束、软偏好、日期和阅读目的，
由 agent 推导概念、英文术语和检索式。不要强制用户编辑每个表格或理解 API。
占位文字、空值、过期路径与无法读取的 secret 引用都不是配置完成。
启用服务的含义也可用自然语言表达，存在歧义时只澄清影响执行的项目。
只有“希望使用”且 key 缺失时要提供选择，不自动关闭该服务。

目录相对于用户配置文件，skill 资源相对于 SKILL.md。没有配置时可创建空白文件；
这次已有研究需求仍保留，不向公开示例写入用户问题。不要把旧 JSON profile
自动迁移为明文密钥。用户指向旧配置时提取可用偏好并帮助整理新文档，保护原文件。

## 能力与服务

| 检查 | 可得结论 | 不能推断 |
|---|---|---|
| 读取配置、输出目录可写 | 路径可用；可以保存结果 | 已开始检索或下载 |
| 搜索/网页/连接器 | 本次确有相应调用能力 | 所有数据库可访问 |
| PDF/正文与图片工具 | 实际能阅读哪些内容 | 有链接就等于读过图表 |
| EasyScholar 等启用服务的 key/引用 | 已提供；或缺失/不可读 | key 有效、额度充足、评级准确 |
| 安全小请求返回服务成功状态 | 此次请求有效 | 全部数据集、年份或期刊已核验 |
| 机构入口/账号/会话 | 可准备登录或验证会话 | 登录成功或文章有订阅 |
| 下载与文件工具 | 可以获取并检查本地文件 | 任何 PDF 已保存或身份正确 |

优先用已有合法连接器和会话。key 只发送到预定服务域名，密码只用于用户确认的学校
登录来源和配置域名。不得把 key 放进公开搜索、普通引用链接、截图或错误输出。
若 API 将 key 放在请求 URL，使用能避免公开 URL/重定向/日志暴露的私密请求工具。
宿主不具备该能力时不要粘贴真实 key 到工具参数，说明限制并让用户选择替代方式。
不安装新连接器、不购买订阅、不放宽宿主权限来自动解决配置缺口。

## 缺项分支

1. 先根据本次任务补齐普通推导项，如检索词、日期解释。
2. 仅列出影响本次已启用功能的真实缺口、后果和可选替代。
3. 请求用户选择“补全后再开始”或“本次接受这些限制继续”。此时不挖掘论文。
4. 选择补全就等待；明确接受后执行可用部分，保留科学约束和未核验状态。
5. 每个新检索 run 重新检查；本次选择只适用于本次，不默改永久偏好。
   同一 run 已接受且未变化的缺口不反复询问；新出现的重大能力损失需说明并调整。

本次记录 preflight.md：时间、配置路径、脱敏后的有效需求、实际可用能力、服务状态、
缺口、用户选择及原话依据。不得复制整份含私密内容的配置到运行目录。
缺少禁用的学校访问不阻止 OA 检索，缺少 IF 不应偷偷放松明确的 IF 硬约束。
