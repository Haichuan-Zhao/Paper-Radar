# 由宿主执行的证据评审

评价由当前 agent 在 harness 内执行；本协议不是自动验证器。
先保存可回访证据，再写评价与分数。按篇/小批处理，使用
[评审模板](../assets/review-template.md)，避免把大量全文混在同一上下文而丢失版本对应。

## 阅读与主张核对

1. 读取用户原始需求，标清对象、任务、硬约束、软偏好和阅读目的。
2. 尽可能先评价内容，再查看作者名望/期刊评级。无法遮蔽元数据时如实注明。
3. 按 [获取协议](fulltext-access.md) 读取实际版本的全文、方法、结果、局限、
   相关主图/表格和决定性补充材料，核实身份并记录材料来源/时间。
   实际查看图片后才记“看过”，索引页/摘要/图注不等于已阅读全文或看图。
4. 建立“问题 → 缺口 → 方法为何适用 → 主张 → 结果/反证”的链条。
   打开最接近的已有工作比较任务、假设、方法和证据，再判断创新；只凭“首次”自述不评分。
5. 覆盖全部核心结论，以及影响推荐的创新/最好结果/复现主张；
   不把重要问题降成非核心以保住分数，也不要求每篇凑固定条数。
6. 逐维给分和依据；核验每项概念与硬约束。已知事实、作者报告和评审推断分开。
7. 从每条优势、局限、阅读理由及重大批评返回来源反向核对，主动找限制条件、
   替代解释和相反证据。保存核查范围、时间和仍未解决的问题。
8. 距评分门槛 5 分以内、低置信、严谨性/证据 <=2 或 major/critical 问题需针对性复核。
   不能解决则待评/专家复核，不以增加小数位制造准确感。

保存当前宿主/模型标识（可用时）、时间和量表 content-v4。
本次自查不能称为独立盲评、独立复现或科学认证。

## 证据与版本

每条证据有唯一 E-ID、类型、真实来源 URL/本地文件、页/节/图/表/公式/代码位置、
短而准确的原文摘录或实际观察及获取时间。用户需求单独作为需求锚点。
全文证据属于被评版本；外部已有工作显式标为 prior work，不能冒充本篇正文。
同一论文的摘要、结论和结果要区分位置，重复同一句话不是多条独立支持。

每份评审记录候选 ID、DOI/原生 ID、发表版本、实际阅读版本、材料来源、获取方式、
身份锚点、主图数量及确实查看的图/表/补充材料清单。只看到接受稿就明确评价接受稿；
版本变化不继承评分。不把网页链接存在、文件后缀或 HTTP 200 当作证据已经读到。

## 核心主张审查

| 字段 | 记录要求 |
|---|---|
| C-ID / role / central | 唯一 ID；主要结论/创新/主要结果/复现/其他；是否影响核心贡献成立 |
| claim / claim evidence | 简短准确的作者主张原文及 E-ID，必须在所引位置真实存在 |
| support / limits | 支持与限制/反证各自的 E-ID；缺少时如实留空 |
| verdict | supported / qualified / unsupported / contradicted / unresolved |
| scope | 实际研究对象、数据/条件、对照、指标和假设范围 |
| rationale / bounded conclusion | 判断理由及证据允许的保守表述，数值仍归因作者报告 |
| verification | 对负面结论/复现声明记录方法、过程、不同位置证据与局限 |

supported 需要不同于主张位置的实际正文/结果/图表支持；页首身份锚点、
作者重复宣称或把同一引文换 ID 都不能验证结论。创新还需外部已有工作比较。
qualified 表示只有收窄后才有支持；unresolved 表示目前材料或解释仍不够。

unsupported/contradicted 需要针对性交叉核查、重算、证明检查或实际复现，
使用区别于最初主张/疑点位置的证据，并说明复核如何排除了可能解释。
没有这种核验就保持 unresolved/suspected，不能称为已确认错误。
仅检查方法可复核性不等于独立复现；只有真实执行与结果对照才能声称 reproduction。

## 防止论文和评审自身 overclaim

- 分开“作者报告”“读到/观察到”“据此判断”。审稿通过、作者单位、高 IF 和代码
  链接不是结论正确的证明。
- 保留样本/独立单位、数据/工况、预算、假设与适用范围。模拟不自动证明部署有效，
  相关不等于因果，一个数据集或特定假设下的效果不扩写成普遍优越。
- 比较方法时核对任务、划分、基线、预算和指标；百分比区分绝对/相对与分母。
  均值变化不自动显著；统计要求按设计判断，不机械要求所有理论/仿真都有 p 值。
- “首次/唯一”限于实际比较范围，未找到前作不能证明不存在前作。
- 区分没看、没获取、正文未报告、已被反驳。未读补充材料不能说作者没做实验；
  报告不充分与方法错误是不同判断。
- 阅读代码不等于运行，程序运行成功不等于复现论文结果；只链接仓库不评为已复现。
- 图片异常先提问，不能单凭观感指控造假。严重批评核对正文、补充材料、
  正式更正和合理解释；无证据不能写确定性指控。

优势、局限和阅读理由分别引用 C-ID/E-ID，标明 author_report 或 reviewer_assessment；
阅读理由同时对应用户原话。不能用“很创新/顶刊/图很好看”代替证据。
findings 记录 minor/major/critical、suspected/confirmed、受影响主张、证据与验证；
critical 必须关联核心贡献。无核查依据的重大批评不进入确定结论。

## 0–5 分锚点

允许 0.5 步长。0 是已核实的严重不足，未知使用 null/待评；3 表示该类型研究可靠有用，
4 表示强证据，5 需要特别充分的外部比较/验证，不能仅来自流畅文风和精美排版。

| 维度 | 0–1 | 2 | 3 | 4–5 |
|---|---|---|---|---|
| motivation | 问题不清或缺口与已知证据矛盾 | 缺口弱、方法动机跳跃 | 问题具体且方法联系可信 | 必要性和重要缺口有充分依据 |
| originality | 已核实重复且无新增价值 | 小改进、比较不足 | 可识别新增贡献/综合价值 | 最接近工作对比充分，贡献突出且被验证 |
| rigor | 核心设计/证明失效 | 重要控制、基线或假设不足 | 设计/证明合理且限制明确 | 公平对照/稳健性/证明边界充分 |
| evidence | 主张无支持或被结果反驳 | 部分支持、外推或不确定性不足 | 适当证据支持明示范围 | 多角度支撑且排查主要替代解释 |
| reproducibility | 关键步骤/材料经查仍缺失 | 细节/资源部分可核查 | 方法、参数或证明足够复核 | 版本/流程可追溯；5 需实际独立复现 |
| figures | 关键尺度/单位等使证据无法解释 | 比较、样本或图注不完整 | 图表可解释并对应主张 | 表达与可比尺度支持严格判断 |

图表质量评判证据表达，不按配色/软件/作者名加分。确定性曲线不强求误差条，
实验则核查 n、重复类型和变异定义。没有图的理论论文用公式/表格/全文表达评价该维度，
不得因无图自动扣分，也不得虚构“看过图”。

按论文类型调整证据要求：实证关注设计/泄漏/公平比较；理论关注假设/证明与反例；
综述关注来源/纳排/证据层级与综合贡献；资源关注采样/标注/覆盖/许可/版本。
受控数据不自动等于不可复核。领域特定实验只按实际主张需要检查，不固定套一种研究范式。
