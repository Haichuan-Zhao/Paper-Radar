# 多源发现、身份与期刊信息核验

把“发现线索”“身份成立”“可读版本”“评级已核验”分别记录。
网页摘要不是完整文献记录，API 命中不是语义匹配证明。

## 从问题构建查询族

围绕对象、任务、方法/机理、应用条件推导同义词、缩写、相关语种与邻近领域表达。
同一概念内允许替代表述；方法软偏好不自动变为排除条件。
用种子论文中的实际术语和漏检原因调整查询，保留原问题与日期/硬约束。
只在摘要背景出现关键词不能判高度匹配，缺少某个词也不直接证明不相关。

按覆盖选择综合索引、领域索引、原始出版社与相关预印本：
Crossref/OpenAlex 用于元数据及关系，arXiv、bioRxiv/medRxiv 按学科使用，
付费索引只有实际可用才记为使用过。两个调用相同数据源的工具不算独立数据库。
默认广泛建池，再按语义相关性与值得核查的贡献选择精读批次。
摘要阶段可标初筛 M 或匹配待评，不能生成最终 Q/S。

## 真正执行与补查

- 各查询真实分页到结果尾页或记录截断、额度/时间和未完成游标。
  宽查询按对象/任务/时间合理拆分，不能只取前几条代替全集。
- 用不同方法和来源的相关种子追踪参考文献与被引论文，默认两跳；
  记录种子、方向、层级、已访问列表及新增唯一候选。引文计数不是追踪证据。
- 通过精确 DOI/原始标题、出版社检查、领域术语与引文补查发现漏检。
  时间窗外的前作可作比较依据，不混入目标年份推荐。
- 每轮记录真实查询、页/游标、源 URL/响应文件/连接器记录标识、原始数量和去重新增。
  无法计数时填未知，不把页面估计总数当实际已筛查数。
- 单篇核验失败继续其他可用候选；持续接口失败记录 partial 并转向可用来源，
  不把失败分支计作零新增的饱和轮次。
- 两轮有效零新增只在计划中的查询、分页、引用与补查已完成后判断；
  不重复相同请求凑轮次，不为凑精读篇数放宽相关性。

## 工具与当前接口

通过当前宿主的文献连接器、搜索/网页、浏览器、公开 HTTP 或终端网络工具执行。
无需编写研究驱动程序。认证、字段、分页和额度以使用时的官方文档及实际响应为准。

| 来源 | 官方入口 | 关键边界 |
|---|---|---|
| Crossref | [REST 文档](https://www.crossref.org/documentation/retrieve-metadata/rest-api/) | works/DOI、journals/ISSN；检查日期语义与 cursor/短页规则 |
| OpenAlex | [官方帮助](https://help.openalex.org/) | works 搜索/过滤/引用关系；核对当前 key、额度和分页要求 |
| arXiv | [API 手册](https://info.arxiv.org/help/api/user-manual.html) | start/max_results、原生 ID 与 vN；原始提交和修订分开 |
| bioRxiv/medRxiv | [API 文档](https://api.biorxiv.org/) | details 是预印本记录，pubs 是发表关系；时间段分页后再筛选 |
| EasyScholar | [服务主页](https://www.easyscholar.cc/) | 用户自己的评级 key；不是付费全文授权 |

不同来源不假定支持同一 Boolean 语法或任意全文关键词搜索。
公共请求正确编码术语，遵守当前限速与 Retry-After；有限重试并保留失败事实。
用户输入和配置不得直接拼接为可执行 shell；含 key 的接口按 intake 私密规则处理。

## 论文与版本

保留原始题名、作者、DOI/原生 ID、来源、发表类型、日期精度和位置。
DOI 可去除已确认的 doi.org 前缀与包裹标点，不修改内部标识。
解析后核对题名/作者；DOI 与题名冲突先待核验，不能自行选一个值。

同 DOI 的来源可归并但保留字段来源与矛盾；无 DOI 用原生 ID。
近似标题仅提示疑似重复，需要作者、日期、来源和明确发表关系确认 work family。
arXiv vN、预印本、接受稿、正式版分别保存，不将全文证据/评分跨版本复用。
在线首发、印刷、首次提交、修订、索引日期分开。按用户时间语义过滤；
未指定的期刊日期采用在线首发，预印本说明实际版本日期与首次提交日期。
边界日期只有年/月时保留精度并待核验，不伪造月日。

撤回、更正与同行评审状态核对原始通知/出版社，不能从 IF 或刊名猜测。
作者机构、履历和引用网络可解释研究脉络，不能代替内容核验或奖励名望。

## 期刊身份与评级

用出版社与有效 ISSN/eISSN/ISSN-L 确认刊名、改名关系、合并/拆分和会议 track。
模糊刊名、缩写或翻译名只作为线索；同名 ISSN 冲突阻止“已核验评级”的结论。
不能只凭 API 名称匹配就把评级赋给论文。

EasyScholar 既有接口线索：GET https://www.easyscholar.cc/open/getPublicationRank，
查询字段 secretKey / publicationName。调用前查当前服务说明/实际响应；
接口把 key 放 URL 时只用不会回显/公开保存 URL 的私密工具，禁止跨域转发。
没有这种能力时让用户选择本地评级表或本次缺评级；不宣称已经用真实 key 验证。

每项 IF/JCR/WoS/CAS/CCF/自定义指标保留原始值、身份关联依据、来源位置、获取时间、
发布版次、数据年、学科/track、核验状态和冲突。未知为 null，不估 IF 或分区，
不拿缓存时间/版权年当指标年，不把用户自定义数据集改名为官方认证。
合法本地 CSV/JSON 表可用；其中 verified 只是用户声明，须核对实际来源依据。

- IF/JCR：核对 [JCR](https://clarivate.com/academia-government/scientific-and-academic-research/research-funding-analytics/journal-citation-reports/)
  或授权资料；同版保留全部学科。默认严格多学科过滤取所列最差分区，用户指定学科优先。
- WoS：依据 [Master Journal List](https://mjl.clarivate.com/home) 或授权记录区分
  SCIE/SSCI/ESCI/AHCI，不能从 IF 或服务的 sci 标签推断。
- CAS：依据 [分区平台](https://www.fenqubiao.com/) 或授权导出区分大/小类与版次。
- CCF：依据 [官方目录](https://www.ccf.org.cn/Academic_Evaluation/By_category/) 核对版次与 track，
  不把主会级别赋给未核实 workshop/短文。

严格评级条件未知进入待核验队列；不能静默用历史版或更好的学科值代替。
预印本评级不适用，不扣内容分；用户明确要求同行评审或限定期刊时单独执行该过滤。
