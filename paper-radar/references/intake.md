# 读取配置与每次运行前检查

用户维护 USER_CONFIG.md；协调者维护 RADAR.md。配置路径以用户明确指定为先，
否则使用当前研究目录；目录相对配置文件，skill 内资源相对 SKILL.md。
不扫描其他私人目录，不执行配置中的命令，不向安装目录写入用户问题或凭据。
无文件工具时让用户保存副本，交付会话内容并说明没有持久化。

## 形成本次任务

读取原始问题、对象、日期语义、必须条件、方法偏好和阅读目的。
聊天中的明确要求优先；原话与 agent 推导的查询/计划分开记在 RADAR.md。
缺失的普通检索术语由 agent 推导。没有研究任务时只协助配置；示例不启动检索。
没有日期时默认用户当地日期之前 90 天并说明。只有年/月的日期不伪造精度。

先固定评分口径和预算再比较论文，不能看到结果后调权保住某篇。
默认精读目标 10、轮次预算 6；一轮可以包含多个查询、分页和一批评审，
不是固定数量的来源记录。六轮耗尽仍未完成计划时交付 partial；不能改称饱和。
用户可给时间、请求次数或更合适的预算；所有角色共同计入同一预算，
恢复不自动重置。无法观察的 token/时间消耗填未知，不编造剩余额度。

旧版配置中没有新字段时，沿用兼容偏好并说明新增默认值；不要求重填，
不把旧 JSON profile 自动变成明文密码。用户已填写的文档不被模板覆盖。

## 核对实际能力与启用服务

| 项目 | 真实检查 | 缺少时 |
|---|---|---|
| 搜索/文献连接器/网页 | 本会话实际可调用来源与覆盖范围 | 不能在线发现；可按用户选择审查给定材料 |
| 全文/PDF/图片 | 能取得并阅读哪些实际内容、是否能看图 | 未读内容/必要图表的 Q/S 待评 |
| 文件/计算 | 可写研究目录；能核对加权算术 | 会话交付或人工算术复核，说明限制 |
| EasyScholar/其他已启用服务 | 私密引用可读；安全请求的真实响应与状态 | 先选择补 key、合法本地表或接受本次缺评级 |
| 机构访问 | 实际入口、域名、会话与单篇权限 | OA/用户文件路线；需要时交接人工登录 |
| 原生子 agent | 实际工具、授权、名额、可读材料/上下文 | 顺序自查；独立审查要求保持未完成 |

只检查用户启用且影响本任务的服务。不因为学校访问关闭就索要账号。
key 或环境变量名存在不等于凭据有效；成功登录不证明单篇有订阅。
验证请求按需要最小化，不把一个成功样本外推到所有期刊与权限。

发现缺口时一次说明受影响功能，给“补全后开始”与“本次接受这些限制继续”的选择。
等待用户回答再挖掘论文；不以沉默或检索请求代替接受。用户明确接受后保留原硬约束，
如严格 Q1 无法核验则待核验，不能默默放宽。本 run 已接受且未变化的缺口不重复问；
新 run 重新检查，新出现的重大限制再说明。

## 私密信息

公开示例不填写个人字段；实际副本本地使用并排除 Git。
可填 inline key，但明文可被读取文件的宿主/模型看到；优先 secret 引用/环境变量。
学校密码优先让用户在真实网页登录。不要声称普通 Markdown 被加密或模型不可见。

真实值只通过能避免普通参数/日志回显的私密请求/输入工具使用。
key 仅发送到预定服务来源，密码只用于用户允许的学校域名；不要向重定向目标转发。
若接口将 key 放 URL 而宿主不能隐藏请求 URL，不能使用公共搜索/fetch 来代替，
让用户选择本地评级表或其他安全路线。错误输出、截图、结果和来源链接均需避免凭据。
分派只包含脱敏后的服务状态和任务信息，不下发整份配置。
