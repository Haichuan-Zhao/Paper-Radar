# 实际全文、机构会话与选择后下载

获取情况独立于 Q/M。第一步可以合法打开全文、相关 SI 和必要临时阅读缓存；
正式批量归档/交付 PDF 及文献库写入等待第二步选择。

## 评价阶段的获取

依当前宿主使用出版社 OA/HTML/PDF、可靠学术库/作者接受稿、用户文件或已授权会话；
可选 Unpaywall/Europe PMC 等路线按实际工具与学科覆盖使用。
OA 标签/链接不等于可读，摘要页不等于全文。精确核对 DOI/原生 ID、题名与版本，
保留来源、获取时间、已读范围、实际查看的图/表和缺口。
接受稿、预印本、正式版分开评审；不能跨版本沿用分数。
缺全文者保留 pending_access、值得获取的原因与当前匹配判断，不认证“高质量”。

EasyScholar 提供评级，不能授予收费全文；OA 查询联系邮箱不同于学校登录邮箱。
只给邮箱密码无法确定学校 SSO、订阅与单篇权限，没有通用登录器。

## 使用用户自己的图书馆

读取启用状态、机构、真实图书馆/SSO 入口、允许域名、账号及私密引用/会话说明。
优先复用用户已登录浏览器，从实际页面确认访问路径和具体论文的授权。
需要代填且用户已授权时核对 HTTPS 来源和允许域名，新 SSO 域名先确认再发送凭据。
凭据用宿主私密提交能力；无法避免普通参数回显时由用户在真实页面输入。
MFA/二维码/验证码由用户操作；登录成功后再次检查单篇权限。
403、API 无全文、无 OA 标签不能单独证明学校没有订阅。
不自动购买、改变代理或提交额外超出范围的账号。没有机构浏览器工具时明确交接。

记录真实状态：线索未验证、OA 实际可读、机构实际授权、用户文件、
登录待完成、订阅未知/受限、只摘要、全文未得。会话与密码不能进入公共 URL/日志。

## 第二步：针对固定清单执行

1. 按 run ID/目录修订解析用户选择，核对固定编号、题名、ID 与版本；
   子集和重排不改变编号。“全部推荐”仅指该目录中明确推荐的集合。
   去重选择，不自行加入其他高分论文。已有明确选择不重复问同一授权。
2. 只下载所选正文，保存到配置目录，避免覆盖不明文件。SI、Zotero/其他库导入、
   通知和邮件需另行明确请求；评价阶段临时看过 SI 不等于归档全部附件。
3. 原选版本不可得但有另一稿件时，说明差异，让用户选择是否替换后再下载；
   评分不跨版本迁移，目录与实际版本的差异如实记录。
4. 核验真实文件存在、实际格式、可读页面/页数、题名/DOI/原生 ID 与版本，
   排除 HTTP 200 的登录 HTML、错误页、损坏或错文。
   能用时算 SHA-256 帮助文件去重，哈希不是身份或科学正确的证明。
5. 保存逐篇 manifest：原始选择依据、run/目录/编号/ID、无凭据来源 URL、
   路径、格式/页面/身份/版本的实际检查、哈希（可用时）、结果/失败与未核验项。
   无下载或验证工具时提供可访问链接/交接，不能声称保存或全部成功。

文献库写入只用实际支持的连接器，核对目标库/collection 和 DOI/版本重复，
不直接改数据库、不覆盖既有字段。条目创建与附件分别记录；
附件失败只重试缺失部分，不重复建条目。无连接器可按请求提供 RIS/BibTeX，
这不等于已导入。保存结果后更新 RADAR.md 的下载状态与恢复位置。
