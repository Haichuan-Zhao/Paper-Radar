# 全文评审、主张边界与 Q/M/S

量表 paper-content-v2，分数由宿主判断和计算，不是机器保证或统计校准。
先固定口径、需求和材料版本，读取 [逐篇模板](../assets/review-template.md)，
先保存证据再下判断。可分批精读；广泛候选不要求一次全部给质量分。

## 原始证据先于解释

实际阅读方法、结果、局限、相关图表与决定性补充证据，并核对版本身份。
索引、摘要、图注不能替代全文或看图；没有图的理论论文评公式/证明与表达。
看过的图/表逐项登记。材料不全说明具体缺口，不把未获取写成作者没做。

每条证据 E-ID 包含类型、原始来源 URL/文件、页/节/图/表/公式/代码位置、
短准确摘录或实际观察、获取时间和材料版本。需求单独作为需求锚点。
外部前作标 prior work；重复一句自述或改 E-ID 不会产生独立支持。
关键数值归因“作者报告”；实际观察与 reviewer_assessment 分开。

先核对核心贡献链：问题 → 实际缺口 → 方法为何适用 → 主张 → 支持/限制/反证。
创新判断打开最接近前作，比较任务、假设、方法和证据，不凭“首次”自述评分。
作者名望、IF、引用数、文笔和配色不加 Q/M 分。无法遮蔽这些信息时说明。

## 核心主张与重大批评双向核查

每条影响贡献或推荐的核心结论、新颖性/最佳结果/复现主张记录：

| 字段 | 内容 |
|---|---|
| C-ID / central / role | 是否核心、主结论/创新/主要结果/复现等角色 |
| claim | 作者短原文及实际存在的 E-ID |
| support / limits | 支持与限制/反证 E-ID，各自位置与条件 |
| verdict | supported / qualified / unsupported / contradicted / unresolved |
| scope / rationale | 实际对象、数据、条件、对照、假设、理由与保守结论 |
| verification | 针对性核查方式、不同位置证据、复算/复现范围、未排除解释 |

supported 需要不同于主张位置的实际结果/证明/图表依据；题名/结论复述不是验证。
qualified 只在收窄范围后成立；unresolved 是材料或解释尚不能判断。
unsupported/contradicted 需针对性交叉核查、证明检查、必要复算或实际复现，
用区别于初始主张/疑点位置的证据排查合理解释；未做到则保持 unresolved/suspected。
不能把没有找到支撑当成已经证伪，或让评审者反复修改直到支持预定答案。

findings 记录 minor/major/critical、suspected/confirmed、受影响 C-ID、
证据与验证。critical 必须关联核心贡献。提出重大批评也须读正文、补充与更正：
例如“没有基线”需检查附录；图形异常只作待核查问题，不能凭观感指控造假。

按设计检查样本与独立单位、划分/泄漏、基线公平性、预算、假设和范围。
均值变化不自动显著；百分比区分分母/绝对相对；模拟不自动证明部署、相关不等于因果。
实证、理论、综述、资源论文分别按设计/证明、来源纳排、采样标注等适用证据判断，
不机械要求所有论文都有 p 值或误差条。受控数据不自动不可复核。
读代码不等于运行，运行成功不等于复现论文；不默认开展新的大规模实验。

## 0–5 分的依据

允许 0.5 步长；0 是已核实严重不足，未知用 null/待评。3 表示该类型研究可靠有用，
4–5 需要更强比较与证据，不能仅因版式精美。五分可复现性须有实际独立复现依据。

| Q 维度 / 权重 | 0–1 | 2 | 3 | 4–5 |
|---|---|---|---|---|---|
| motivation / 15 | 问题不清或缺口被证据否定 | 缺口或方法动机弱 | 具体问题与方法联系可信 | 重要缺口和必要性充分 |
| originality / 15 | 经核查重复且无新增价值 | 小改进/比较弱 | 新增认识、方法或综合价值可辨识 | 近邻前作对比充分且贡献突出 |
| rigor / 25 | 核心设计/证明失效 | 控制、对照或假设不足 | 设计/证明合理且边界清楚 | 公平比较、稳健性或证明充分 |
| evidence / 25 | 核心主张无支持/被反驳 | 支持局部且有外推 | 证据支持明示范围 | 多角度支持并排查替代解释 |
| reproducibility / 10 | 关键步骤经查仍缺 | 细节/资源部分可核查 | 方法参数或证明足够复核 | 流程/版本可追溯，5 需实际独立复现 |
| figures / 10 | 尺度/单位使证据不可解释 | 图注/比较/样本信息欠清楚 | 图表/公式可解释且对应主张 | 表达与可比尺度支持严格判断 |

M 每维同时引用用户需求与论文内容，不把“有相关词”当匹配：
problem 45（对象与任务）、approach 25（方法对本问题的实际可用性）、
context 20（工况/材料/迁移前提）、intent 10（阅读目的）。
软偏好允许合理替代路径；明确必需方法或部署条件则作为硬约束单独核验。

Q/M = Σ(权重 × 维度分/5)，范围 0–100。
S = Q^α × M^(1−α)，默认 α=0.60，允许 0–1；用实际计算工具复核输入与算术。
保留原始分项、约束后的有效值和理由，用未四舍五入值判断门槛，显示可保留一位。
没有计算工具则说明人工核对方式和限制，不伪造计算调用。

## 门槛先于综合排名

默认最低 Q/M=70 且 rigor/evidence>=3/5；用户的更明确门槛优先。
同时满足证据、硬约束与核验要求，S>=85 为 must_read，75<=S<85 为 shortlist；
其余完整评审可作 watchlist，不凑高质量篇数。无论用户如何调权都保留证据门槛：

| 情况 | 输出 |
|---|---|
| 缺全文/必要图表、创新比较或任一分项依据 | 维度 null；最终 Q/S 待评，可给有依据的初筛 M |
| 核心主张 unresolved、重大疑点未解决 | needs_expert_review；最终 Q/S 待评 |
| 影响推荐的 qualified 主张 | evidence<=3/5、置信<=medium、推荐至多 shortlist，写保守结论 |
| 经针对核查核心 unsupported | 不推荐，S 不计算 |
| 核心 contradicted 或确认核心缺陷 | 排除/待专家处理，S 不计算 |
| 硬约束或严格评级未知 | needs_verification，不列为符合条件的推荐 |
| 硬约束确认失败 | 明确排除，不用高综合分抵消 |

未评维度不填零/均值或重分配权重；有需要可展示敏感性上下界但不拿它们推荐。
review_confidence=low/medium/high 描述证据充分性，不是校准的正确概率。
距门槛 5 分内、低置信、rigor/evidence<=2 或重大问题，做有针对性的复核；
无新证据不反复打分至通过。独立性单列 self_check/independent/limited，
单 agent 自查可形成有边界的评审，但不满足用户明确要求的独立评审。

没有因为获取难度、预印本无 IF、未知作者或负结果而直接扣 Q。
评价权重是阅读决策启发式，尚无领域准确率/召回率基准；不要把排序当科学定论。
