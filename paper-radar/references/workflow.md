# 检查、协作与恢复

## 每次新研究前

读取指定配置或工作区 USER_CONFIG.md，不扫描其他私人目录或执行配置中的命令。
从用户原话明确对象、问题、日期语义、硬约束、软偏好和阅读目的；检索式由 agent 推导。
无日期时说明默认当地日期之前 90 天；不伪造只有年/月的日期精度。
默认精读目标 10、最多六轮实质性工作；一轮可含多查询、分页和一批评审。
所有角色共享预算，恢复不重置；未知的时间/token 消耗不编造。先固定评分再比较。

检查实际搜索/全文/图片/文件/计算/子 agent 能力，以及用户启用的评级、机构服务。
key 或变量名存在不证明有效，登录不证明单篇有订阅；只做必要的最小验证。
相关缺项一次说明影响，让用户选择补全后开始或本次接受限制；等待回答再挖掘。
原硬约束不因接受缺项而放宽。本 run 同一缺口不重复问，新 run 重新检查。
关闭的服务不索要账号；示例、保存配置和沉默不是研究或委派授权。

配置是本地明文，宿主/模型可能看到；优先 secret 引用和真实网页登录。
真实值只交预定服务，避免普通参数、URL、错误输出和日志回显；不转发到新域名。
EasyScholar 的 key 若只能出现在公开工具 URL 中，改由用户选择本地评级表或本次缺评级。
子 agent 只得到脱敏状态和任务材料，不下发整份私人配置。

## 职责与交接

协调者保留原始问题、选缺口、分配预算，独占写共享进展、候选汇总和最终目录。
使用原生通用子 agent 绑定下列职责即可，不需要额外宿主角色文件：

| 职责 | 读取/执行 | 返回 |
|---|---|---|
| 发现 | search.md、access.md；真实检索、分页、引用与取证 | 查询/页码、候选 ID/版本、原始材料、未完成分支 |
| 核验 | search.md、review.md；直接检查原始来源与证据位置，最后复核评分算术/门槛 | 身份/评级冲突、已查与未查项、最小修正 |
| 评审 | review.md；先读用户问题及正文/图表/近邻前作，再看发现方解释 | C-ID/E-ID、Q/M 分项或待评、保守结论、最小补证 |

分派包含原始任务、脱敏约束、本轮问题、实际协议路径、冻结输入修订、工具边界、
预算与独占写入区。审查不覆盖材料；材料变更产生新修订，只复核受影响项。
记录真实 agent ID、所审版本、是否参与上游判断、上下文 inherited/clean/unknown。
尽量用新上下文；读过同一修订并参与判断后再检查只能算自查。
无真实委派能力或授权时顺序执行并标 self_check，用户的独立评审要求仍待满足。
角色消息不是完成证据；等待实际产物，保留分歧，不靠投票或反复修订保证高分。

## 一轮与停止

一轮解决一个实质缺口：覆盖遗漏、身份冲突、关键证据或影响推荐的主张/批评。
按 [输出约定](outputs.md) 记录实际来源/查询/日期、页或引文方向/层级、返回与新增唯一数、
固定材料、核验/评审意见、耗用、决定和下一步。失败与未执行不填成零新增。
分别统计来源记录、唯一 work family、具体版本、相关候选、引用新增、深读与待读。

- 本次计划完成：计划查询族、可用来源分页和默认两跳引用真实执行，再观察到连续两轮
  有差异的有效扩展零新增范围内合格唯一候选；仍说明未深读部分，只报有界覆盖。
- partial：预算、额度、上下文或访问使分支未完成；保存精确游标和可继续动作。
- paused/blocked：用户暂停，或必需输入/授权缺失且无可推进工作；记录解除条件。

常规失败继续其他可用工作；低分、一次 API 错误或不够推荐篇数不是整个任务结束。
不自动创建新聊天或后台任务，预算耗尽不偷偷继续，也不把十篇/六轮当覆盖证明。

## 恢复与版本

恢复读取 RADAR.md 顶部和相关历史，核对候选、材料、目录实际存在且版本对应，
从缺失步骤继续，不无理由重跑第一页；旧“运行中”和旧 agent ID 不证明仍有进程。
保留已接受限制、原始意见与剩余预算。旧配置缺新字段时沿用兼容值并说明默认项。
保留 paper-radar-v2 目录和 paper-content-v2 量表；升级 skill 不重写既有评分/编号。
更换主题、日期或硬约束另起 run；发布后新增/重评创建目录新修订并保留旧版。
