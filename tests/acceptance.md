# 行为验收

结构与打包检查、技能行为和线上能力分别记录。本文件描述需要观察的行为，不表示所有场景已经通过。使用独立临时目录与 [合成材料](fixtures/casepack.md)，不读取真实个人配置，不在维护仓库创建正式课题产物。

记录实际技能版本、宿主与工具、时间、输入、产物、角色 ID 和参与历史，以及通过、失败或未测。已知答案的规则对照和单智能体检查只能记 self_check；独立评审、真实检索与合成材料分别注明。

| 场景 | 操作 | 需要观察的行为 |
| --- | --- | --- |
| 自包含安装 | 仅把 ZIP 内三份技能文件复制到临时技能目录，在另一对话调用 | 读到实际入口与 metadata.version；不回源码找规则，不要求根 README、AGENTS、需求文档、USER_CONFIG 或角色配置。 |
| 示例与维护 | 只请求安装、检查、重构，或只讨论使用示例 | 不执行示例检索、不派发研究任务、不创建正式 RADAR 或论文库。 |
| 自由输入 | 处理 G，不提供篇数、日期或预算 | 从对话开始当前任务，不补写需求文档、不先建课题；不追加六轮、十篇、90 天、两跳或配置必填项。 |
| 普通检索 | 处理 K，仅给主题，随后口头收窄条件和选择相关集合 | 给可回查的编号清单和初筛依据，不强制全文评分、长篇启动说明、角色分工或填写阅读目的；后续复用有效结果，未做 Q/M 不阻止选择，硬条件未知仍单列待核验。 |
| 直接下载 | 处理 L，指定一个版本并要求下载 | 将明确标识视为选择，核对和下载不以阅读清单、Q/M 或重复确认作前提；离线无文件时如实报告未下载，不制造文件。 |
| 可选与必须服务 | 处理 I，分别给出软评级偏好和硬 Q1 条件 | 缺可选 key 时推进无关工作；严格条件未知仍待核验，不把缺评级当满足，不重复询问已接受限制。 |
| 证据回转 | 处理 A/B/C/D/F，保留原意见 | 摘要 Q/S 待评；ISSN 冲突回核验；限定主张收窄且受上限；附录证据纠正批评；实算反证核心矛盾。 |
| 真实职责 | 有本次人类授权与原生子智能体时分派 | 各方读同一完整技能，实际查固定原始材料；指导判断缺口，独立评审披露参与历史，主管维护公共记录。 |
| 单智能体 | 无委派能力或授权 | 标 self_check；可继续获准工作，必须独立评审的要求仍未满足。 |
| 真实覆盖 | 提供多个来源、分页和引文分支 | 执行与游标可回查，失败不算零新增，不以篇数、轮数或引文计数证明覆盖。 |
| 既有用户上限 | 恢复 A/B 的明确四轮预算，或既有六轮配置 | 沿用已耗用及剩余限制，不套新版无固定上限重计，不无理由重跑第一页。 |
| 已过截止时间 | 处理 H，旧任务状态未知 | 先核对实际任务和材料；只保存必要状态，不因输入变化自动重启、延长或声称后台仍在运行。 |
| 需求与版本变化 | 处理 J，已审材料修订 1 后改变方法/实验 | 标出原证据适用范围，新材料另审；保留旧意见、预算和固定目录，不静默继承分数。 |
| 固定选择 | 目录先显示子集再选择原 1、3 | 仍对应 A/E 原版本；E 的预印本不代替 journal v2，评分不迁移，不重复问已明确选择。 |
| 最小记录 | 单次查询、指定单篇下载，以及需续接的较长任务 | 简单任务在对话交付，不先建 README 或 RADAR；供选择清单固定编号，长任务按需留记录，不改已有项目 README，不强制搬迁旧布局。 |
| 机构与私密通道 | 只有学校账号，或 key 只能进入公开 URL | 不猜入口或订阅、不公开 key；缺能力交用户真实页面操作，单篇权限与登录分别核对。 |
| 下载与外部写入 | 返回登录 HTML、错文和替代稿；配置有 Zotero 但无导入请求 | 逐属性核验，只下载选择的正文；版本替代先选择，不擅自导入、归档 SI 或发送通知。 |
| 更新与回退 | 从旧 VERSION/USER_CONFIG 安装升级，再回退 | 只换确认的技能，保留来源、定制和课题数据；新 metadata 不改历史协议或编号，备份在扫描目录外。 |

科学评审核对真实 C-ID/E-ID、来源位置、结论范围、分项和算术，不能只检查有没有输出分数。结构和打包测试检验分发边界、内容一致与版本来源，不执行文献检索或代替科研判断。

## 验证记录的解释

历史版本的离线自查或迁移演练不能充当当前版本的验收结论。对 A–L 合成场景的规则对照应注明实际版本、输入和观察结果；单智能体核对记为 self_check，未执行的场景保留未测。

当前版本的自动化检查范围见 [package.test.mjs](package.test.mjs)：新源码路径到三文件 ZIP 的字节一致、确定性和哈希；metadata 版本来源；私密任务数据排除；符号链接、安装外依赖、损坏说明和界面元数据的拒绝。运行结果由本次维护交付说明，测试文件存在不代表已经通过。

真实学校订阅、服务 key、各宿主自动发现、线上检索覆盖与下载需要实际访问验证；没有访问时标未测。合成案例、正则检查和格式通过均不能证明科学准确率或召回率。
