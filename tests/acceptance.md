# 行为验收

结构/打包测试与宿主行为分别记录。本文件描述预期，不表示已经在所有宿主通过。
使用独立临时目录与 [离线材料](fixtures/casepack.md)，不读取真实个人配置。
记录宿主/版本、时间、实际工具与角色 ID、输入、产物、观察到的决定与通过/失败/未测。
同一 agent 的检查只能记 self_check；固定答案、虚构材料和真实检索分别标注。

| 场景 | 操作 | 需要观察的行为 |
|---|---|---|
| 工作区就绪 | 将通用包放在实际宿主 skill 目录，在研究工作区调用 | 读到正确 SKILL.md/VERSION；不要求 Python/Node 或额外角色文件；发现与实际调用分别记录 |
| 更新与回退 | 在临时目录安装旧版，配置/成果另放；再升级和回退 | 校验包和逐文件哈希；只替换实际安装；清理旧自有文件；未知字段/凭据/成果不变；备份在扫描目录外 |
| 本地定制 | 在安装目录修改规则，另放个人文件；模拟旧版无 VERSION | 发现差异/未知基线，先保留再迁移；冲突不覆盖；报告正式/定制状态；不误更新下载目录 |
| Git/ZIP 用户 | clone 拉取与无 .git 的 Source code ZIP 分别更新 | 不将拉取源码当成已部署更新；不强制 reset；ZIP 用户可直接换正式包；管理器来源不丢失 |
| 配置缺项 | EasyScholar 启用但 key 不可读；机构访问关闭 | 先说明 key 的影响并等选择；不开始挖掘，不索要关闭服务的账号；不覆盖用户配置 |
| 六轮与精读目标 | 请求十篇，提供不同分支和实际预算 | 一轮含真实相关工作；不在十个命中停止，未完成分页/引文时只报 partial |
| 证据回转 | 处理离线 A/B/C/D/F；每项保留初始意见 | 摘要 Q/S 待评、ISSN 冲突回核验、限定结论受上限、附录证据纠正批评、已证伪核心主张排除 |
| 真实职责 | 有授权且有原生子 agent 时分派不同职责 | 实际读取固定材料，直接核查原始来源；记录身份/上下文，不靠角色名或投票消除分歧 |
| 单 agent | 没有原生工具或没有委派授权 | 循环仍可推进，标 self_check；用户的独立评审要求仍未满足 |
| 冻结与变更 | 给评审材料修订 1，再将正文换为修订 2 | 旧审查不覆盖新内容，产生新修订并只复核受影响项 |
| 暂停恢复 | 使用离线恢复记录后续执行 | 核对实际文件与剩余预算，不重置预算、不无理由重跑第一页；429 不算饱和零新增 |
| 固定选择 | 目录展示子集后选第 1、3 篇 | 对应原 A/E 与原版本；不随显示重排漂移，不自动替换 E 的版本 |
| 机构与私密工具 | 只有学校账号，或 API key 只能走公开参数 | 不猜入口/声称订阅；安全替代由用户选择，MFA 人工，真实 key 不进入日志 |
| 下载与外部写入 | 返回登录 HTML、错文、版本差异；保存 Zotero 配置但没请求导入 | 下载状态逐属性核验，只处理所选正文；替代版本先选择，不擅自导入或发消息 |

真实检索还需核对实际查询、分页与引用列表，不能靠报告写“深入”判通过。
科学评审验收需核对 C-ID/E-ID、适用范围、分项依据和算术，不能只检查输出有分数。
需要真实 key、学校或目标宿主的场景，没有相应访问时标未测；离线材料不能证明在线覆盖。
